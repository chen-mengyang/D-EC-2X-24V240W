# D-EC-2X-24V240W

中端 EtherCAT 总线型 BLDC 方波驱动器，一拖二拓扑：单板独立驱动左／右两路电辊筒，配双网口 EtherCAT 级联、左右各一组传感器输入与数字量输出。对标台邦 GBLD 一拖二通讯型驱动卡 EtherCAT 版（GBLD2408A-2/Ecat、GBLD4808A-2/Ecat）做参数对齐替代，核心优势为自研 EtherCAT 从站栈 + 价格优势。文中电气数值、过程数据协议口径对标参考手册，为参考目标而非本产品实测值；实际规格以定型与样机测试为准，未定型处标 TBD。

> 状态：规划中（编写依据：台邦《GBLD 一拖二通讯型驱动卡 EtherCAT 版 简要说明》2026 年 8 月版）｜文档更新：2026-11-11

- 产品线：驱动器（D）
- 产品编码：D-EC-2X-24V240W（D=驱动器线，EC=EtherCAT，2X=一拖二拓扑，24V=电压，240W=单板合计额定功率规格码）
- 适用客户：使用 EtherCAT 总线的辊筒厂、输送与分拣设备厂
- 典型主站：CODESYS V3.5 SP14 Patch 1+ 或同类 EtherCAT 主站 PLC（对标手册案例为禾川 Q1-1300-D3）

### DI／DO 接线方法

本产品与对标产品的接线差异：

- 输入固定 PNP：只接 PNP 型传感器（信号为 +24V 有效），不提供 NPN 接法。
- 每个输入点位独立供电：每个点位各自引出 +24V、0V 和信号三根线，传感器从本点位取电；对标产品是多个输入点位与输出共用一组电源，本产品不是。
- 因此接线时按「一个点位一组线」逐一对应，不要把多个点位的 +24V 或 0V 并在一起。
- 信号与协议对应：SEN／AUX 一类输入信号以位形式上报主站（SEN_IN_x、AUX_IN_x）；D01／D02 是否输出由 SENTYPE_x 的 Bit8／Bit9 置 1 使能。
- 输入供电端子命名、信号有效电平与阈值以实物与定型为准；DO 接电磁阀等感性负载时需考虑外部续流／保护，隔离与保护方式以定型为准。
- IO 推荐线径：AWG24-16（对标参考），按实际电流选取。

### 接线步骤

1. 断电接线：按实物照片接电源、左右电辊筒与霍尔、DI／DO 传感器与负载、EtherCAT IN／OUT。
2. PNP 传感器按点位逐个接各自的 +24V／0V（一个点位一组线，不跨点位并接电源），确认驱动卡与辊筒良好接地。
3. EtherCAT 级联：主站网线接 IN，下一级从站接 OUT。
4. 上电检查指示灯：电源、NS／MS 网络与模组状态、左右电机状态灯。
5. 主站导入 ESI XML、添加从站、映射地址。
6. 配置 SENTYPE_x 的 D01／D02 输出使能（Bit7 保持 0，输入固定 PNP）、极对数、加减速度、最大转速。
7. 置 P485_control_x 为 1，下发 UartDIR_x 与 UartSpeed_x，观察运行与反馈变量；验证 DI 触发、DO 动作与故障保护，再投入运行。

### 指示与保护

NS 网络状态指示灯：关闭＝无电源或无 IP 地址；绿色常亮＝在线且已建立连接；绿色闪烁＝在线但未建立连接；红色＝IP 地址重复或严重错误；红色闪烁＝连接超时。

MS 模组状态指示灯：关闭＝无电源；绿色常亮＝由运行态扫描器控制；绿色闪烁＝未配置或扫描器空闲；红色＝严重故障；红色闪烁＝可恢复故障（参数不匹配）。

左右电机状态灯与报警闪码（红灯闪 N 下 + 绿灯闪 1 下）：

| 状态 | 含义 |
| --- | --- |
| 绿灯常亮／绿灯闪烁 | 待机／电辊筒运行 |
| 红 1 下 | 超速 |
| 红 2 下 | 过压 |
| 红 3 下 | MOS 管过流 |
| 红 4 下 | 过流 |
| 红 5 下 | 欠压 |
| 红 6 下 | 霍尔故障 |
| 红 7 下 | 堵转 |
| 红 8 下 | 过温 |

故障反馈 Fault_x（x=1 为左轴／1#，x=2 为右轴／2#）：Bit8-Bit10 为霍尔数值显示，Bit0-Bit7 为上表故障码（0 正常、1 超速、2 过压、3 瞬间过流／MOS 管过流、4 过载／过流、5 欠压、6 霍尔故障、7 堵转、8 过温、9 驱动器内部故障）。故障复位方式由控制字 UartDIR_x 的 Bit9 选择（0 手动／1 自动）。本产品沿用该协议定义，故障状态机与映射待定型。

### EtherCAT 过程数据变量（与对标产品一致）

变量名、位定义与初始匹配值全部沿用对标手册口径，x=1 为左轴（1#），x=2 为右轴（2#）。方向：主站 → 从站为设定／控制，从站 → 主站为反馈。

硬件相关注记：本产品输入固定 PNP，因此 SENTYPE_x 的 Bit7 固定置 0（不使用 NPN 选项），该位仅为协议兼容保留；Bit8／Bit9 的 D01／D02 输出使能照常使用。

| --- | --- | --- | --- |
